Bounty - Rhythm Game



Description

In this rhythm game, you play as a hunter in a mystical forest. Shoot the bugs on beat to survive.


Motivation

IMDM101 Final group project, we wanted to create something that would let us express our creativity. This project was meant to be a somewhat large undertaking given the ~30 day timeline we had.

Game Mechanics:

  • The current betmap implementation is through a "BeatObject" class. These are added to an array in the editor and then converted to a stack in the "BeatMap" script. Data from these "BeatObject" elements are then converted into a GameObject and instantiated.


Problems Encountered:

Resolution was a big issue for us. The backgrounds create at first were not large enough, they then became too large. If we wanted to have a consistent screen size black bars would appear or we would need to cut off some of the scene.



Future Work

  • Revamp the beatmap creation system to be interactive (creation of beatmaps using buttons in its own scene rather than through the editor)
  • Adding more sound effects (hit sounds, menu button sounds, damage sounds)
  • Create more levels and increase gun mechanics (ammo counts/reload mechanic)
